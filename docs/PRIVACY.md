# プライバシーポリシー

家計簿アプリ「家計簿」（以下「本アプリ」）での情報の取り扱いについて説明します。

## 集める情報

本アプリは、利用者の情報を集めたり、外部へ送ったりしません。

- 入力した収入・貯金・固定費・生活費・特別出費・予算などの記録と、アプリの設定は、お使いの端末の中にだけ保存されます。
- 本アプリは、記録や端末の情報を開発者や第三者のサーバーへ送りません。
- 広告、アクセス解析、トラッキングは使っていません。本アプリが使っている部品（Syncfusion の .NET MAUI コントロール）が持つ利用状況の送信機能も、止めています。

## 第三者との共有

利用者の情報を集めないため、第三者（解析ツール、広告ネットワーク、外部の SDK など）と共有する情報もありません。

## 生体認証（Face ID・Touch ID・指紋認証）

設定で生体認証をオンにすると、起動するときに端末の生体認証で本人確認をします。認証は端末の OS が行い、本アプリが受け取るのは「認証できたかどうか」だけです。顔や指紋の情報を本アプリが読み取ったり保存したりすることはありません。

## バックアップ

「バックアップを作成」では、記録と設定を1つのファイルにまとめ、利用者が選んだ場所に保存します。保存先（端末の中、iCloud Drive、Google ドライブなど）での取り扱いは、その保存先のサービスの規約に従います。端末の標準のバックアップ（iCloud バックアップなど）に、本アプリの記録が含まれることがあります。

## 外部のページ

設定の「利用規約」「プライバシーポリシー」「お問い合わせ」は、GitHub のページをブラウザで表示します。そのページでの情報の取り扱いは、[GitHub のプライバシーステートメント](https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement)に従います。

## 保存期間と削除

- 記録と設定は、利用者が削除するまで端末の中に保存されます。
- 記録は、各一覧で1件ずつ削除できます。本アプリを削除すると、端末の中の記録と設定もすべて削除されます。
- 開発者は利用者の情報を持っていないため、開発者に削除を依頼していただく必要はありません。

## 同意の取り消し

生体認証は、設定でいつでもオフにできます。本アプリの使用をやめるときは、本アプリを削除してください。

## お問い合わせ

本ポリシーと本アプリについてのお問い合わせは、[GitHub の Issues](https://github.com/ken-mro/KakeiboApp/issues) で受け付けています。

## 改定

本ポリシーを改定するときは、このページを更新します。

# 計算式一覧

アプリに表示される金額と、その計算方法をまとめたものです。使い方は [HOW_TO.md](HOW_TO.md) を参照してください。

- 計算は [Services/BudgetCalculator.cs](../Services/BudgetCalculator.cs) にまとまっています。ホームの金額は、すべて `BudgetCalculator.Summarize` が返す [MonthSummary](../Models/MonthSummary.cs) から表示します。
- 一覧の件数と合計は [Services/EntryService.cs](../Services/EntryService.cs) が `BudgetCalculator` を使って求めます。
- テストは [KakeiboApp.Tests](../KakeiboApp.Tests) にあります。刷新前のバージョン1.0と同じデータで同じ合計になることも、テストで確認しています（`BudgetCalculatorSummaryTests`）。
- 式を変えるときは、このドキュメントとテストも合わせて更新してください。

## 前提

- **選択月**：画面上部で選んだ年月です。内部では「その月の1日」（例：2026/10/01）として扱います。
- **月の判定**：「選択月の」データとは、日付の年と月が選択月と一致するものです（`BudgetCalculator.IsInMonth`）。
- **「先月まで」**：日付が選択月の1日より前のデータすべてです。前月だけでなく、それ以前の全期間を含みます。
- **切り崩し**：貯金データのうち、金額がマイナスのものです。
  - 例：旅行の貯金から3,000円取り崩す → 名前「旅行」、金額−3,000の貯金データとして保存されます。

## 収入・貯金・固定費

| 表示 | 式 | コード |
|---|---|---|
| 収入の合計 | 選択月の収入の金額の合計 | `MonthSummary.IncomeTotal` |
| 貯金の合計 | 選択月の貯金のうち、金額が0より大きいもの（切り崩しを除く）の合計 | `BudgetCalculator.SavingsInMonth`, `MonthSummary.SavingTotal` |
| 固定費の合計 | 選択月の固定費の金額の合計 | `MonthSummary.FixedCostTotal` |

ホームでは、貯金と固定費を「−¥50,000」のように差し引く金額として表示します。

## 生活費

| 表示 | 式 | コード |
|---|---|---|
| 生活費の合計 | 種類ごとの「出費」の合計 | `MonthSummary.SpendingTotal` |
| 予算の合計 | 種類ごとの「予算」の合計 | `MonthSummary.BudgetTotal` |
| 出費（種類ごと） | 選択月の生活費のうち、その種類のものの金額の合計 | `BudgetCalculator.BuildBudgetControlResults` |
| 予算（種類ごと） | 選択月に登録したその種類の予算。未登録なら0（「予算なし」と表示） | `BudgetCalculator.BuildBudgetControlResults` |
| 種類ごとのバー | 出費 ÷ 予算（100%で止める）。予算がない種類は0 | `CategoryBudgetRow.Ratio` |
| 「オーバー」 | 予算があり、出費が予算より多い | `CategoryBudgetRow.IsOver` |
| 生活費の合計の色 | 予算の合計があり、生活費の合計がそれより多いとき `DeficitInk` | `MainPageViewModel` |
| 残りの予算 | 予算 − 出費（予算のシートに表示） | [BudgetControlResult.RemainingBudget](../Models/BudgetControlResult.cs#L8) |
| 1日あたり（種類ごと） | 下の表を参照（予算のシートに表示） | [BudgetControlResult.GetDailySpending](../Models/BudgetControlResult.cs#L11) |

### 1日あたり（種類ごと）

まず、残りの予算が0以下なら **0** です。それ以外は、選択月と今日の関係で決まります。

| 選択月 | 式 |
|---|---|
| 過去の月 | 残りの予算（日割りしない） |
| 今月 | 残りの予算 ÷（今月の日数 − 今日の日 + 1） |
| 未来の月 | 残りの予算 ÷ その月の日数 |

- 今月の場合、日数には今日を含みます。例：10月15日なら`31 − 15 + 1 = 17`日で割ります。
- 未来の月は、月の初日から使い始める前提で、その月の全日数で割ります。うるう年の2月は29日です。

## 先月までの残高

[BudgetCalculator.TotalRemainingUntilPreviousMonth](../Services/BudgetCalculator.cs#L52)

```
先月までの残高 = 収入の合計 − 貯金の合計 − 固定費の合計 − 生活費の合計
                （いずれも選択月より前の全期間）
```

- 貯金の合計には切り崩し（マイナスの金額）も含みます。つまり「貯金した額 − 取り崩した額」の正味の額が引かれます。
- 特別出費は含みません（仕様。下の「特別出費」を参照）。
- 表示場所は設定によって変わります。
  - 「残りのお金を翌月に繰り越す」がオン：ホームの「今月使えるお金」の **先月の繰り越し** の行
  - オフ：「貯金の内訳・切り崩し」画面の **先月までに残ったお金（貯金を除く）**

## 今月使えるお金

[BudgetCalculator.MonthlyUsableMoney](../Services/BudgetCalculator.cs#L93)

```
繰り越しオフ：今月使えるお金 = 収入の合計 − 貯金の合計 − 固定費の合計
繰り越しオン：今月使えるお金 = 先月までの残高 + 収入の合計 − 貯金の合計 − 固定費の合計
```

先月までの残高がマイナスの場合は、そのまま差し引かれます。

## 残りのお金

[BudgetCalculator.MonthlyRemainingTotal](../Services/BudgetCalculator.cs#L107)

```
残りのお金 = 今月使えるお金 − 生活費の合計 + 切り崩し
```

| 表示 | 式 |
|---|---|
| `うち切り崩し ¥...` | 選択月の切り崩し額の合計（`MonthSummary.LivingOff`）。0のときは表示しません |
| 文字色 | 残りのお金が0未満なら `DeficitInk`、それ以外は `Ink` |

## 今月のペース

[BudgetCalculator.Pace](../Services/BudgetCalculator.cs#L197)、[MonthPace](../Models/MonthSummary.cs)

ホームの「残りのお金」のカードに、2本のバーで表示します。

| 表示 | 式 |
|---|---|
| 日数のバー | 経過日数 ÷ その月の日数 |
| 日数の数字 `15/31日` | 経過日数 / その月の日数 |
| 支出のバー・割合 | 生活費の合計 ÷（今月使えるお金 + 切り崩し） |
| 支出のバーの色 | 支出の割合が日数の割合より大きいとき `Deficit`、それ以外は `Accent` |

経過日数と残りの日数は、選択月と今日の関係で決まります。

| 選択月 | 経過日数 | 残りの日数 |
|---|---|---|
| 過去の月 | その月の日数 | 0 |
| 今月 | 今日の日（今日を含む） | その月の日数 − 今日の日 + 1（今日を含む） |
| 未来の月 | 0 | その月の日数 |

- 支出の割合の分母は、生活費に使えるお金です。残りのお金と同じく切り崩しを足します。
- 分母が0以下のときは、生活費が1円以上なら100%、0円なら0%です。
- 支出の割合は100%を超えることがあります（例：120%）。バーは100%で止めます。
- 例：10月15日、今月使えるお金が¥300,000、生活費が¥210,000 → 日数は15/31日（48%）、支出は70%。支出のほうが先に進んでいるので、使いすぎのサインです。

### 1日あたり（残りのお金）

`MonthPace.DailyAllowance`。考え方は種類ごとの1日あたりと同じで、残りの予算の代わりに残りのお金を使います。

| 条件 | 式 |
|---|---|
| 残りのお金が0以下 | 0 |
| 過去の月 | 残りのお金 |
| 今月・未来の月 | 残りのお金 ÷ 残りの日数 |

`あと17日` は残りの日数です。過去の月では表示しません。

例：10月15日、残りのお金 ¥90,000 → ¥90,000 ÷ 17日 = ¥5,294。

## 先月までの貯金の内訳

[BudgetCalculator.SavingsUntilPreviousMonth](../Services/BudgetCalculator.cs#L70)、[SavingResult](../Models/SavingResult.cs)

| 表示 | 式 |
|---|---|
| 行 | 貯金の名前ごとに1行です。同じ名前の貯金をまとめます |
| 貯金 ¥… | 選択月より前の、その名前の貯金の合計（切り崩しを差し引いた正味） |
| 今月の切り崩し ¥… | 選択月にその貯金から取り崩す額（正の数で表示・入力） |
| 右の金額 | 貯金 − 今月の切り崩し |
| 貯金総額 | 各行の「貯金 − 今月の切り崩し」の合計（`MonthSummary.SavingBalanceTotal`） |

- 金額の合計が0の貯金は表示しません（全額を取り崩し終えた貯金など）。
- 切り崩しは、日付が選択月の1日ちょうどの、マイナスの貯金データと名前で結び付けます。
- 切り崩しに入力できるのは、1円以上で、その行の貯金以下の金額だけです。切り崩しをやめるときは、行をけします。

## 特別出費

特別出費は、生活費とは別枠で記録するための項目です。

**仕様：特別出費は「先月までの残高」「今月使えるお金」「残りのお金」から差し引きません。**

旅行や冠婚葬祭のような一時的な大きな出費で、毎月の生活費のやりくりが崩れて見えないようにしています。

| 表示 | 式 | コード |
|---|---|---|
| ホームの特別出費の合計 | 選択月の特別出費の金額の合計 | `MonthSummary.SpecialExpenseTotal` |
| 特別出費の一覧の「年間の合計」 | 選択年の特別出費の金額の合計 | `BudgetCalculator.SpecialExpenseTotalInYear` |
| 追加時の日付の初期値 | 選択月が今月なら今日、それ以外は選択月の1日 | `BudgetCalculator.DefaultSpecialExpenseDate` |

## 一覧

[EntryService.LoadAsync](../Services/EntryService.cs)

| 一覧 | 対象 | 並び | 合計 |
|---|---|---|---|
| 収入・固定費 | 選択月 | 登録した順 | 金額の合計 |
| 貯金 | 選択月の、金額が0より大きいもの | 登録した順 | 金額の合計 |
| 生活費 | 選択月 | 日付ごとにまとめ、新しい日が先。同じ日の中では新しく登録したものが先（`BudgetCalculator.GroupByDay`） | 金額の合計 |
| 特別出費 | 選択年 | 生活費と同じ | 年間の合計 |
| 貯金の内訳 | 先月までの貯金 | 名前ごと | 貯金総額 |

- 件数は一覧の行の数です。
- 生活費の一覧の合計は、予算の合計があり、それより多いときに `DeficitInk` で表示します。

## データがない月

[BudgetCalculator.IsEmptyMonth](../Services/BudgetCalculator.cs#L184)

選択月に収入・貯金・固定費・生活費・予算・切り崩し・特別出費が1件もないとき、ホームは眠っているぶたの案内を表示します。
「残りのお金を翌月に繰り越す」がオンで、先月までの残高が0でないときは、データがない月として扱いません。

前月に固定費があり、選択月の固定費が0のときは、「◯月の固定費が◯件あります」と「◯月にコピーする」を表示します。

## 先月からコピー（固定費）

[BudgetCalculator.CopyFixedCostsFromPreviousMonth](../Services/BudgetCalculator.cs#L113)

- 選択月の前月（1月なら前年の12月）の固定費を、選択月の新しい行として追加します。
- 内容・金額・メモは同じで、日付だけ選択月の1日になります。

## 金額の表示と入力

[MoneyFormat](../Services/MoneyFormat.cs)

- 金額は円で「¥90,000」のように表示します。マイナスは「−¥5,000」です。
- 1円未満は四捨五入します（0.5は切り上げ）。1日あたりの金額などに小数が出るためです。
- 入力欄では、全角数字・カンマ・「¥」「円」も受け付けます。登録できるのは1円以上の整数です。

## 仕様上の注意点

- 特別出費は「先月までの残高」「今月使えるお金」「残りのお金」のどれにも含まれません（仕様）。
- 貯金の合計には切り崩しが含まれません。一方、先月までの残高では切り崩しを差し引いた正味の貯金額を使います。
- 「コピーする」は重複を確認しません。2回押すと同じ固定費が2件ずつ登録されます。
- バージョン1.0では、金額を端末の地域設定の通貨形式で表示していました。バージョン2.0からは、地域設定にかかわらず円で表示します。

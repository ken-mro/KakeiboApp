# 家計簿アプリの使い方

月ごとの収入・貯金・固定費・生活費・特別出費を記録し、「今月あといくら使えるか」を確認するアプリです。
各金額の計算方法は [FORMULAS.md](FORMULAS.md) にまとめています。

## 画面の構成

画面下のタブで5つの画面を切り替えます。

| タブ | 画面 | できること |
|---|---|---|
| ホーム | サマリー | 月ごとの収入・貯金・固定費・生活費・残りのお金・特別出費の確認と編集 |
| 生活費の登録 | 登録 | 日々の出費（生活費）の入力 |
| 生活費 | 生活費の一覧 | 選択した月の生活費を種類ごとに確認・編集 |
| 特別出費 | 特別出費の一覧 | 選択した年の特別出費を確認・編集 |
| 設定 | 設定 | テーマ、指紋認証、繰り越しの設定 |

## はじめに：認証

- アプリを開くと、最初はホームタブだけが表示されます。
- 設定で「指紋認証」をオンにしている場合は、指紋の確認画面が出ます。認証すると、ほかのタブとデータが表示されます。
- キャンセルした場合は、ホーム画面下の「認証」ボタンからやり直せます。
- 指紋認証がオフの場合は、自動で認証済みになります。

## 月を選ぶ

- ホームと生活費の画面上部のボタン（例：`2026 Oct`）をタップすると、年月を選ぶダイアログが開きます。
- 選んだ月は全画面で共通です。ホームで月を変えると、生活費・特別出費の画面にも反映されます。
- 特別出費の画面では、選んだ月の「年」全体が表示されます。
- 選べる範囲は2020年1月から2100年1月です。

## ホーム画面

ホームには色分けされた6つのセクションがあります。見出しをタップすると開閉します。
開いたセクションの右上にある更新ボタン（↻）で、表の内容を読み込み直せます。

### 収入（緑）

- その月の収入の一覧と合計です。
- 「追加」から内容・金額・メモを入力して「登録」します。

### 貯金（黄）

- その月に貯金した金額の一覧と合計です。
- 「追加」から内容（例：旅行、車）・金額・メモを入力します。
- 切り崩しは、貯金の内容名ごとに行います。同じ目的の貯金は毎月同じ名前で登録してください。

### 固定費（青）

- 家賃や光熱費など、毎月決まって出ていくお金です。
- 「追加」で1件ずつ登録します。
- 「先月からコピー」で、前の月の固定費をまとめて今月にコピーできます。
  - 押すたびにコピーされるので、2回押すと2件ずつ登録されます。
  - 重複した行は、金額を0にすると消せます（後述）。

### 生活費（オレンジ）

- 見出しには、その月の生活費の合計と、予算の合計 `(予算: ...)` が表示されます。
- 開くと「今月使えるお金」と「種類ごとの内訳」の表が表示されます。

| 列 | 意味 |
|---|---|
| 種類 | 食費・日用品・雑貨・娯楽・車・医療・その他 |
| 1日あたり | 残りの予算を、残りの日数で割った金額 |
| 残りの予算 | 予算 − 出費 |
| 予算 | その月のその種類の予算。この列だけ編集できます |
| 出費 | その月にその種類で使った金額 |

- 予算を入力すると、その月の予算として保存されます。
- 予算に0を入力すると、その月の予算は削除されます。

### 残りのお金（紫）

- 今月使えるお金から生活費を引いた金額です。マイナスになると赤字で表示されます。
- その月に貯金を切り崩した場合は、`(うち 切り崩し: ...)` として内訳が出ます。
- 「残りのお金を翌月に繰り越す」がオフの場合は、「先月までの貯蓄額（貯金除く）」も表示されます。
- 「先月までの貯金の内訳」の表には、先月までに貯めた貯金が内容ごとに表示されます。
  - 「切り崩し」列に金額を入力すると、その月にその貯金から取り崩した額として記録されます。
  - 取り崩した額は、その月の「残りのお金」に足されます。
  - 貯金額より大きい金額や、マイナスの金額は受け付けません。
  - 0を入力すると切り崩しを取り消せます。

### 特別出費（赤）

- 旅行や冠婚葬祭など、生活費とは別に管理したい大きな出費です。
- 「追加」を押し、日にち・内容・金額・どこから（支払い元）・メモを登録します。
- 日にちの初期値は、選択中の月が今月なら今日、それ以外の月ならその月の1日です。
- 特別出費は生活費とは別枠です。「今月使えるお金」「残りのお金」「先月の繰り越し額」からは差し引かれません（仕様）。

### 先月の繰り越し額

- 設定で「残りのお金を翌月に繰り越す」をオンにすると、ホーム上部に「先月の繰り越し額」が表示されます。
- この金額は「今月使えるお金」に加算されます。

## データの追加・編集・削除

### 追加

- ホームの各セクションの「追加」ボタン、または「生活費の登録」タブから行います。
- 登録すると画面下に確認メッセージが表示されます。
- 追加用の画面は、登録後も開いたままです。続けて入力でき、外側をタップすると閉じます。
- 日にちが2020年より前の場合は、エラーになります。
- 金額は1以上を入力してください。

### 編集

- 表のセルをタップすると、その場で編集できます。
- 入力を確定すると保存されます。

### 削除

- **金額のセルに0を入力して確定すると、その行が削除されます。** 削除ボタンはありません。
- 収入・貯金・固定費・特別出費・生活費の一覧で同じ操作です。

## 生活費の登録

1. 「生活費の登録」タブを開きます。
2. 日にち（初期値は今日）・種類・内容・金額・メモを入力します。
3. 「登録」をタップします。
4. 確認メッセージが出て、入力欄が初期状態に戻ります。

## 生活費の一覧

- 選択した月の生活費が、種類ごとにグループ表示されます。
- グループの見出しには、その種類の合計が表示されます。
- 見出しをタップするとグループを開閉できます。開閉の状態は保存されます。
- 各セルはその場で編集できます。金額を0にするとその行が削除されます。

## 特別出費の一覧

- 選択した年の特別出費がすべて表示され、`総額` に年間の合計が表示されます。
- 各セルはその場で編集できます。金額を0にするとその行が削除されます。

## 設定

| 項目 | 内容 |
|---|---|
| テーマ | システム・ライト・ダークから選びます |
| 指紋認証 | オンにすると、起動時に指紋認証を求めます |
| 残りのお金を翌月に繰り越す | オンにすると、先月までに使い切らなかったお金を今月の「使えるお金」に加えます |

- 設定は端末に保存され、次回起動時にも引き継がれます。

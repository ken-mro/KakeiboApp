# 家計簿アプリの使い方

月ごとの収入・貯金・固定費・生活費・特別出費を記録し、「今月あといくら使えるか」を確認するアプリです。
各金額の計算方法は [FORMULAS.md](FORMULAS.md) にまとめています。

この文書はバージョン2.0の画面と操作を説明します。アプリの中では「使い方」と「くわしい使い方」で確認できます（下の「アプリ内の使い方」を参照）。

## 画面の構成

画面下のタブで4つの画面を切り替えます。

| タブ | 画面 | できること |
|---|---|---|
| ホーム | 今月の概要 | 残りのお金と今月のペースの確認、生活費をつける、予算を入れる、各一覧をひらく |
| 一覧 | 生活費の一覧 | 選んだ月の生活費を日付ごとに確認、さがす、なおす、けす |
| 特別出費 | 特別出費の一覧 | 選んだ年の特別出費を確認、さがす、つける、なおす、けす |
| 設定 | 設定 | テーマ、指紋認証、繰り越し、使い方、くわしい使い方 |

収入・貯金・固定費・貯金の内訳の一覧は、ホームからひらきます。

## はじめに：認証と使い方

- 設定で「指紋認証」をオンにしている場合は、起動すると指紋の確認画面が出ます。認証するまで、ホームには「指紋認証でひらきます」とだけ表示され、ほかのタブは使えません。
- キャンセルした場合は、ホームの「認証する」からやり直せます。
- 指紋認証がオフの場合は、自動で認証済みになります。
- はじめて起動したときと、アップデートしたあとはじめて起動したときは、認証のあとに「使い方」（すぐに使いはじめるための案内）が表示されます。「スキップ」または最後のページの「はじめる」で閉じると、次の起動からは表示されません。

## 月を選ぶ

- ホームの上部にある「‹」「›」で、前の月・次の月に切り替えます。
- 年月（例：`2026年10月`）をタップすると、年と月を選ぶダイアログが開きます。
- 選んだ月は全画面で共通です。ホームで月を変えると、一覧にも反映されます。
- 一覧のタブでも、タイトルの左右の「‹」「›」で月を切り替えられます。特別出費のタブでは年を切り替えます。
- 選べる範囲は2020年1月から2100年1月です。

## ホーム

### 残りのお金と今月のペース

- いちばん上のカードに「残りのお金」と「1日あたり」に使える金額、今月の残りの日数が表示されます。残りのお金がマイナスになると、赤みのピンクで「−」を付けて表示します。
- 貯金を切り崩した月は「うち切り崩し ¥…」も表示されます。
- 下の2本のバーは今月のペースです。
  - 日数：月の何日目まで来たかを表します。
  - 支出：生活費に使えるお金のうち、どれだけ使ったかを表します。
  - 「支出」のバーが「日数」のバーより先に進んでいたら、使いすぎのサインです。バーが赤みのピンクになります。
- その下に、ぶたからのひとことが表示されます（例：「ちょっと早めのペースです」）。

### 今月使えるお金

- 収入 − 貯金 − 固定費の順に並びます。「残りのお金を翌月に繰り越す」がオンのときは、「先月の繰り越し」の行も表示されます。
- 収入・貯金・固定費の行をタップすると、それぞれの一覧がひらきます。

### 生活費（種類ごとの予算）

- 種類ごとに、その月の出費と予算、予算の消化率のバーが表示されます。
- 予算を超えた種類には「オーバー」のバッジが付き、金額とバーが赤みのピンクになります。
- 種類をタップすると、その月の予算を入れるシートが開きます。金額の下に、次のように表示されます。
  - `10月の食費: ¥4,980`：その月に使った金額です。
  - `残りの予算: ¥45,020(1日あたり ¥2,814)`：予算がある種類だけに表示されます。
- 予算をけすときは、シートの「けす」をタップします。画面の下の「もとに戻す」で戻せます。

### 特別出費・貯金の内訳

- 「特別出費」をタップすると、特別出費のタブに移ります。特別出費は別枠で、残りのお金には入りません。
- 「貯金の内訳・切り崩し」をタップすると、先月までの貯金の一覧がひらきます（下の「切り崩し」を参照）。

### データがない月

- 何も記録されていない月は、眠っているぶたと「◯月はまだまっしろです」が表示されます。「収入を入れる」から収入を入れられます。
- 前の月に固定費がある場合は、「◯月の固定費が◯件あります」と「◯月にコピーする」が表示されます。

## 生活費をつける

1. ホームの「＋ 生活費をつける」をタップします。下からシートが開き、数字のキーボードが出ます。
2. 「いくら使った？」に金額を入れます。
3. 「なにに使った？」で種類をタップして選びます。最初は「食費」が選ばれています。
4. 「登録」をタップします。

- 内容・メモ・日付は「メモや日付も書く（なくてもOK）」をタップすると入れられます。
- 日付を選ばなければ、今日の日付で登録されます。ホームで別の月を表示していても、初期値は今日です。
- 日付は、あとから一覧で行をタップして直せます。
- 続けて入れるときは「つづけて登録」をタップします。シートは開いたままで、金額・内容・メモが空に戻ります。種類と日付はそのままです。
- 今日以外の日付を選んでいるときは、日付を見落とさないように次のようにします。
  - 「つづけて登録」のあとも、日付の欄を開いたままにします。
  - 日付の欄を閉じても、`日付: 10月14日（水）　タップして変える` のように日付を表示します。
  - 登録したことを知らせる文に、日付を入れます（例：`10月14日（水）に「食費」¥980 を登録しました`）。
- 一覧のタブの「＋ 生活費をつける」からも同じシートが開きます。

## 一覧

収入・貯金・固定費・生活費・特別出費は、同じ形の一覧で表示します。

- 上部に件数と合計が表示されます。その下に、なおし方とけし方が表示されます。
- 生活費と特別出費は、日付ごとにまとめて表示します。新しい日付が上です。
- 右下の「＋」ボタンから追加します（例：「＋ 収入を入れる」）。

### なおす

- 行をタップすると、下からシートが開きます。内容を変えて「保存」をタップします。

### けす・もとに戻す

- 行を左にスワイプすると「けす」ボタンが出ます。タップすると、その行がけされます。
- けしたあと8秒ほど、画面の下に「『◯◯』をけしました」と「もとに戻す」が表示されます。「もとに戻す」をタップすると、けした行が戻ります。
- 行をタップして開いたシートの「けす」でも、同じようにけせます。スワイプが使いにくいときや、読み上げを使っているときはこちらを使ってください。
- 前のバージョンの「金額に0を入れるとけす」方法はなくなりました。金額は1円以上を入れてください。

### さがす

生活費と特別出費は、すべての月（特別出費はすべての年）の記録からさがせます。

1. 一覧のタブか特別出費のタブで、タイトルの右にある虫めがねのボタンをタップします。上に入力欄が出ます。
2. さがしたい言葉か金額を入れます。入れ終わると、当てはまる行が表示されます。

- 生活費は内容・メモ・種類から、特別出費は内容・メモ・どこから払ったかからさがします。言葉の一部だけでも見つかります。
- 大文字と小文字、全角と半角、ひらがなとカタカナは区別しません（例：「すーぱー」で「スーパー」が見つかります）。
- 金額として読める言葉（例：`980`、`¥1,200`）は、金額がちょうど同じ行も見つけます。金額の一部だけでは見つかりません（`98`では¥980の行は出ません）。
- 言葉をスペースで区切ると、すべての言葉に当てはまる行だけが表示されます（例：`ランチ 1200`）。
- 結果は日付ごとに、新しい順に並びます。日付には年も表示されます。上部には件数と合計が表示されます。
- 結果の行も、タップしてなおしたり、左にスワイプしてけしたりできます。
- 「とじる」か戻るボタンで、もとの月の一覧に戻ります。

### 収入・貯金・固定費

- ホームの「今月使えるお金」の行からひらきます。左上の「‹」でホームに戻ります。
- 貯金は、内容（例：旅行、車）ごとに切り崩します。同じ目的の貯金は、毎月同じ名前で入れてください。
- 固定費の一覧の下にある「先月の固定費をコピーする」で、前の月の固定費をまとめてコピーできます。押すたびにコピーされるので、重複した行はけしてください。

### 特別出費

- 旅行や冠婚葬祭など、生活費とは別に管理したい大きな出費です。
- 選んだ年の特別出費がすべて表示され、上部に年間の合計が表示されます。
- 「＋ 特別出費をつける」で、金額・内容・日付・どこから払ったか・メモを入れます。
- 日付の初期値は、選んだ月が今月なら今日、それ以外の月ならその月の1日です。
- 特別出費は、「今月使えるお金」「残りのお金」「先月の繰り越し」からは差し引かれません（仕様）。

### 切り崩し

- ホームの「貯金の内訳・切り崩し」でひらきます。先月までに貯めた貯金が、内容ごとに表示されます。
- 行をタップすると「◯◯から切り崩す」シートが開きます。金額を入れて「保存」すると、その月にその貯金から取り崩した額として記録されます。
- 切り崩したお金は、その月の「残りのお金」に足されます。
- その行の貯金より多い金額は入れられません。
- 切り崩しをやめるときは、行を左にスワイプして「けす」をタップします。「もとに戻す」で戻せます。
- 「残りのお金を翌月に繰り越す」がオフのときは、この画面に「先月までに残ったお金（貯金を除く）」も表示されます。

## 入力のきまり

- 金額は1円以上の整数を入れてください。カンマや全角数字も使えます。
- 日付は2020年1月1日から2100年1月1日までです。
- 入力に問題があるときは、シートの金額の下に、何を直せばよいかが表示されます（例：「金額を入力してください。1円以上の金額を登録できます」）。

## 設定

| 項目 | 内容 |
|---|---|
| テーマ | システム・ライト・ダークから選びます。選ぶとすぐに切り替わります |
| 指紋認証 | オンにすると、起動時に指紋認証を求めます |
| 残りのお金を翌月に繰り越す | オンにすると、先月までに使い切らなかったお金を今月の「使えるお金」に加えます |
| 使い方 | すぐに使いはじめるための案内を、もう一度ひらきます |
| くわしい使い方 | 「使い方」で説明していないことを、話題ごとの短い案内でひらきます |

- 設定は端末に保存され、次回起動時にも引き継がれます。
- 画面の下に、アプリのバージョンが表示されます。

## アプリ内の使い方

アプリの中の説明は、実際の画面を指し示しながら進みます。説明する部分だけを明るく残して周りを暗くし、吹き出しで説明します。「次へ」で進み、「スキップ」でいつでも閉じられます。必要なときは、自動で一覧・特別出費・設定のタブに移ります。

- 吹き出しは、下のタブのすぐ上に表示されます。「＋ 生活費をつける」などのボタンを説明するページだけは、そのボタンが見えるように、ボタンの上に表示されます。
- 下のタブは暗くしません。選ばれているタブを見ると、どの画面の説明かがわかります。説明の間は、タブは押せません。
- 指し示す部分は、吹き出しに重ならないように画面の上（上に少し余白を残した位置）に移動します。吹き出しより長い部分は、吹き出しの手前までを明るくします。
- 案内の間は、記録の有無にかかわらず、ホーム・一覧・特別出費の金額をすべて見本の金額（収入¥250,000、生活費¥4,100など）にして説明します。見本の金額で説明しているページでは、吹き出しの右上に「見本の金額」と表示されます。見本の金額は保存されず、案内を閉じると記録した金額の表示に戻ります。
- 使い方を閉じると、ホームの先頭に戻ります。

説明は2種類あります。「使い方」は、はじめに必要なことだけを説明します。「くわしい使い方」は、それ以外のことを話題ごとに説明します。2つの間で、同じ説明はしません。

### 使い方（すぐに使いはじめるための案内）

はじめて起動したときと、アップデートしたあとはじめて起動したときに表示されます。指紋認証がオンの場合は、認証のあとに表示されます。「設定 › 使い方」から、いつでももう一度ひらけます。

| ページ | 指し示す場所 | この文書の該当箇所 |
|---|---|---|
| 1. 残りのお金 | ホームの残りのお金のカード | 「ホーム」の「残りのお金と今月のペース」 |
| 2. まず、今月使えるお金を入れる | 収入・貯金・固定費のカード | 「ホーム」の「今月使えるお金」、「一覧」の「収入・貯金・固定費」 |
| 3. 生活費をつける | 「＋ 生活費をつける」ボタン | 「生活費をつける」 |
| 4. 特別出費をつける | 特別出費タブの「＋ 特別出費をつける」 | 「一覧」の「特別出費」 |
| 5. もっと知りたいときは | 設定の「使い方」と「くわしい使い方」 | 「設定」 |

残りのお金は、今月使えるお金から生活費を引いた金額です。そのため、まず今月使えるお金（収入・貯金・固定費）の入れ方を説明し、次に生活費と特別出費のつけ方を説明します。なおし方とけし方は、一覧の上に表示される案内で確認できます（「一覧」の「なおす」「けす・もとに戻す」を参照）。予算・ペース・切り崩し・検索などは「くわしい使い方」で説明します。

最後のページで、くわしい説明は「くわしい使い方」にあることを伝えます。

### くわしい使い方

「使い方」で説明していないことだけを、話題ごとの短い案内に分けています。「使い方」と同じ説明はしません。設定の「くわしい使い方」の下にある話題をタップしてひらきます。自動では表示されません。

#### 予算とペース（2ページ）

| ページ | 指し示す場所 | この文書の該当箇所 |
|---|---|---|
| 1. 予算をつける | 生活費のカード | 「ホーム」の「生活費（種類ごとの予算）」 |
| 2. 今月のペース | 日数と支出の2本のバー | 「ホーム」の「残りのお金と今月のペース」 |

#### 貯金・切り崩し・繰り越し（3ページ）

| ページ | 指し示す場所 | この文書の該当箇所 |
|---|---|---|
| 1. 貯金の内訳・切り崩し | 貯金の内訳・切り崩しの入口 | 「一覧」の「切り崩し」 |
| 2. 切り崩したとき | 残りのお金のカード | 同上 |
| 3. 繰り越し | 設定の「残りのお金を翌月に繰り越す」 | 「設定」 |

#### つけ方とさがし方（4ページ）

| ページ | 指し示す場所 | この文書の該当箇所 |
|---|---|---|
| 1. 固定費をコピーする | 収入・貯金・固定費のカード | 「一覧」の「収入・貯金・固定費」 |
| 2. 日付と、つづけて登録 | 「＋ 生活費をつける」ボタン | 「生活費をつける」 |
| 3. どこから払ったか | 特別出費タブの「＋ 特別出費をつける」 | 「一覧」の「特別出費」 |
| 4. さがす | 一覧の虫めがねのボタン | 「一覧」の「さがす」 |


## 前のバージョンからの主な変更

| 1.0 | 2.0 |
|---|---|
| ホームは6つの折りたたみセクション | 残りのお金とペースを最初に表示し、各一覧へはタップで移動 |
| 「生活費の登録」タブで5項目を入力 | ホームの「生活費をつける」から、金額と種類だけで登録 |
| 表のセルを直接編集 | 行をタップしてシートでなおす |
| 金額に0を入れて削除（取り消せない） | スワイプして「けす」、「もとに戻す」で取り消せる |
| 予算と切り崩しは表のセルに入力 | 種類や貯金をタップしてシートで入力 |
| 金額は端末の地域設定の通貨形式 | 円（¥）で表示 |

# 家計簿アプリの使い方

月ごとの収入・貯金・固定費・生活費・特別出費を記録し、「今月あといくら使えるか」を確認するアプリです。
各金額の計算方法は [FORMULAS.md](FORMULAS.md) にまとめています。

この文書はバージョン2.0の画面と操作を説明します。アプリの中では「使い方」と「くわしい使い方」で確認できます（下の「アプリ内の使い方」を参照）。

## 画面の構成

画面下のタブで4つの画面を切り替えます。

| タブ | 画面 | できること |
|---|---|---|
| ホーム | 今月の概要 | 残りのお金と今月のペースの確認、生活費をつける、予算を決める、各一覧をひらく |
| 生活費 | 生活費の一覧 | 選んだ月の生活費を日付ごとに確認、つける、さがす、なおす、けす |
| 特別出費 | 特別出費の一覧 | 選んだ年の特別出費を確認、さがす、つける、なおす、けす |
| 設定 | 設定 | テーマ、指紋認証、繰り越し、バックアップと復元、使い方、くわしい使い方 |

収入・貯金・固定費・貯金の内訳の一覧は、ホームからひらきます。

## はじめに：認証と使い方

- 設定で「指紋認証」をオンにしている場合は、起動すると指紋の確認画面が出ます。認証するまで、ホームには「指紋認証でひらきます」とだけ表示され、ほかのタブは使えません。
- キャンセルした場合は、ホームの「認証する」からやり直せます。
- 指紋認証がオフの場合は、自動で認証済みになります。
- はじめて起動したときと、アップデートしたあとはじめて起動したときは、認証のあとに「使い方」（すぐに使いはじめるための案内）が表示されます。「スキップ」または最後のページの「はじめる」で閉じると、次の起動からは表示されません。

## 月を選ぶ

- ホームの上部にある「‹」「›」で、前の月・次の月に切り替えます。
- 年月（例：`2026年10月`）をタップすると、年と月を選ぶダイアログが開きます。
- 選んだ月は全画面で共通です。ホームで月を変えると、生活費のタブにも反映されます。
- 生活費のタブでも、タイトルの左右の「‹」「›」で月を切り替えられます。特別出費のタブでは年を切り替えます。
- 選べる範囲は2020年1月から2100年1月です。

## ホーム

### 残りのお金と今月のペース

- いちばん上のカードに「残りのお金」と「1日あたり」に使える金額、今月の残りの日数が表示されます。残りのお金がマイナスになると、赤みのピンクで「−」を付けて表示します。
- 貯金を切り崩した月は「うち切り崩し ¥…」も表示されます。
- 下の2本のバーは今月のペースです。
  - 日数：月の何日目まで来たかを表します。
  - 支出：生活費に使えるお金のうち、どれだけ使ったかを表します。
  - 「支出」のバーが「日数」のバーより先に進んでいたら、使いすぎのサインです。バーが赤みのピンクになります。
- カードの右上のぶたは、ペースに合わせて変わります。

| 状態 | ぶた |
|---|---|
| いいペース、まだ始まっていない月 | まるいぶた |
| ちょっと早めのペース | 少し痩せたぶた |
| 残りのお金がマイナス | 痩せこけたぶた（コインなし） |
| 終わった月で、お金が残った | にっこりしたぶた |
| 終わった月で、足りなかった | 痩せこけて、しょんぼりしたぶた |

### 今月使えるお金

- カードには「今月使えるお金」と金額だけが表示されます。カードをタップすると内訳がひらき、もう一度タップするととじます。アプリを開いたときは、とじています。
- 内訳には、収入 − 貯金 − 固定費の順に並びます。「残りのお金を翌月に繰り越す」がオンのときは、「先月の繰り越し」の行も表示されます。
- 収入・貯金・固定費の行をタップすると、それぞれの一覧がひらきます。
- 前の月の収入・貯金・固定費は、それぞれの一覧からコピーできます（「一覧」の「収入・貯金・固定費」を参照）。

### 生活費（種類ごとの予算）

- カードには「生活費」と、その月の出費の合計と予算の合計だけが表示されます。カードをタップすると種類ごとの行がひらき、もう一度タップするととじます。アプリを開いたときは、とじています。
- 種類ごとに、その月の出費と予算、予算の消化率のバーが表示されます。
- 予算を超えた種類には「オーバー」のバッジが付き、金額とバーが赤みのピンクになります。
- 予算をまだ決めていない種類には、金額の横に「予算を決める」と表示されます。各行の右端の「›」は、タップできることを表します。
- 種類をタップすると、その月の予算を決めるシートが開きます。このシートは、ほかのシートと同じく画面の上から開きますが、中身の高さの分だけです。キーボードはその下に出ます。金額の下に、次のように表示されます。
  - `10月の食費: ¥4,980`：その月に使った金額です。
  - `残りの予算: ¥45,020(1日あたり ¥2,814)`：予算がある種類だけに表示されます。
- 予算をけすときは、シートの「けす」をタップします。画面の下の「もとに戻す」で戻せます。

### 貯金の内訳・特別出費

- 「貯金の内訳・切り崩し」をタップすると、先月までの貯金の一覧がひらきます（下の「切り崩し」を参照）。
- 特別出費は、ホームのいちばん下に「別枠」の点線で区切って表示します。カードも点線の枠だけにして、残りのお金に入るほかのカードと見分けられるようにしています。特別出費は、残りのお金には入りません。
- 「特別出費」をタップすると、特別出費のタブに移ります。

### データがない月

- 何も記録されていない月は、眠っているぶたと「◯月はまだまっしろです」が表示されます。収入は「＋ つける」から入れられます。
- 前の月に収入・貯金・固定費・予算のどれかがある場合は、「◯月の分をコピーできます」と、それぞれの件数（例：収入2件・貯金1件・固定費3件・予算5件）が表示されます。「◯月にまとめてコピー」で、まとめてコピーできます。予算は、前の月に予算がある種類だけ、同じ金額になります。
- 貯金のコピーには、切り崩しは入りません。

## ＋ つける

ホーム・生活費・特別出費・設定のどのタブにも、収入・貯金・固定費の一覧にも、右下（設定で左下にもできます）に「＋ つける」があります。収入・貯金・固定費・特別出費・生活費は、すべてここから入れます。

- 「＋ つける」に指を置いてフリックすると、ボタンの上に、付箋のように「収入」「貯金」「固定費」「特別出費」「生活費」が上から順に出てきます。付箋は、ボタンと同じ側の画面の端から出ます。ボタンの「＋」は「×」に変わります。
- 指を離さずに付箋の上まですべらせると、その付箋の色が濃くなります。そこで離すと、その種類のシートが開きます。フリック入力と同じ感覚です。
- 付箋の外で指を離すと、付箋は消えて元の「＋ つける」に戻ります。
- 「＋ つける」をタップしただけでは、付箋は出ません。
- 読み上げ（TalkBack）を使っているときは、ダブルタップで付箋が出たままになります。付箋をダブルタップして選びます。付箋の外、「×」、戻るボタンで閉じます。
- 「＋ つける」を左下に置くこともできます（「設定」の「「＋ つける」の位置」）。

## 生活費をつける

1. 「＋ つける」から「生活費」を選びます（「＋ つける」を参照）。シートが開きます。
2. 「日にち」を選びます。最初は今日です。「昨日」をタップすると昨日になり、ほかの日は日付の欄から選べます。
3. 「種類」をタップすると一覧が開くので、選びます。最初は「食費」が選ばれています。
4. 必要なら「内容」（例：スーパー）を入れます。キーボードの「次へ」で「金額」に移ります。
5. 「金額」を入れます。
6. 必要なら「メモ」を書きます。
7. 「登録」をタップします。シートは開いたままなので、続けて次の生活費を入れられます。終わったら右上の「×」で閉じます。

- 欄は、日にち → 種類 → 内容 → 金額 → メモの順に、いつも表示されています。新しくなる前の「生活費の登録」タブと同じ順です。
- シートは画面の上から開き、下のタブの手前で終わります。シートを開いたままタブをタップすると、シートを閉じてそのタブに移ります。保存していない入力があるときは、閉じてよいかを先に確かめます。キーボードは画面の下側に、シートの上から重なって表示されます。キーボードより上の欄を入力している間、シートは動きません。
- キーボードを出している間は、「登録」はキーボードに隠れます。金額の「完了」を押すか、タイトルや欄の外をタップする、または種類の一覧を開くとキーボードが閉じ、入力した内容全体とボタンが表示されます。
- メモのようにキーボードに隠れる欄を入力するときだけ、その欄が見えるところまで画面全体が上にずれます。メモの行が増えると、そのつど少しずつ上にずれます。キーボードを閉じると元に戻ります。新しくなる前の登録画面と同じ動きです。
- 入力に不備があると、その欄が赤い枠になり、すぐ下に理由が表示されます（例：金額が空のとき「金額を入力してください。…」）。不備のある欄が見えるところまで、自動でスクロールします。その欄を直すと、表示は消えます。
- メモは改行して書けます。一覧では、書いた行のとおりに表示されます（「メモ」を参照）。
- 日付を選ばなければ、今日の日付で登録されます。ホームで別の月を表示していても、初期値は今日です。
- 日付は、あとから一覧で行をタップして直せます。
- 「登録」のあとは、金額・内容・メモが空に戻ります。種類と日付はそのままです。シートの下に、登録したことを知らせる文が日付付きで出ます（例：`10月14日（水）に「食費」¥980 を登録しました`）。登録済みの記録をなおすときの「保存」は、保存してシートを閉じます。

### メモ

- どの記録のメモも、改行して何行でも書けます。メモの欄は、書いた分だけ高くなります。
- 一覧では、メモは内容と種類の下に、書いたとおりの行で表示されます。行の頭の空白や、間の空いた行もそのまま表示されます。
- メモの最初と最後の空いた行、行の終わりの空白は、保存するときに取りのぞかれます。

## 一覧

収入・貯金・固定費・生活費・特別出費は、同じ形の一覧で表示します。

- 上部に件数と合計が表示されます。その下に、なおし方とけし方が表示されます。
- 生活費と特別出費は、日付ごとにまとめて表示します。新しい日付が上です。
- 「＋ つける」から追加します（「＋ つける」を参照）。
- 行がない月は、一覧の代わりに眠っているぶたの案内が表示されます。収入・貯金・固定費の一覧では、前の月の行があるとき、その下にコピーの案内も表示されます。

### なおす

- 行をタップすると、下からシートが開きます。内容を変えて「保存」をタップします。

### けす・もとに戻す

- 行を左にスワイプすると「けす」ボタンが出ます。タップすると、その行がけされます。
- けしたあと8秒ほど、画面の下に「『◯◯』をけしました」と「もとに戻す」が表示されます。「もとに戻す」をタップすると、けした行が戻ります。
- 行をタップして開いたシートの「けす」でも、同じようにけせます。スワイプが使いにくいときや、読み上げを使っているときはこちらを使ってください。
- 前のバージョンの「金額に0を入れるとけす」方法はなくなりました。金額は1円以上を入れてください。

### さがす

生活費と特別出費は、すべての月（特別出費はすべての年）の記録からさがせます。

1. 生活費のタブか特別出費のタブで、タイトルの右にある虫めがねのボタンをタップします。上に入力欄が出ます。
2. さがしたい言葉か金額を入れます。入れ終わると、当てはまる行が表示されます。

- 生活費は内容・メモ・種類から、特別出費は内容・メモ・どこから払ったかからさがします。言葉の一部だけでも見つかります。
- 大文字と小文字、全角と半角、ひらがなとカタカナは区別しません（例：「すーぱー」で「スーパー」が見つかります）。
- 金額として読める言葉（例：`980`、`¥1,200`）は、金額がちょうど同じ行も見つけます。金額の一部だけでは見つかりません（`98`では¥980の行は出ません）。
- 言葉をスペースで区切ると、すべての言葉に当てはまる行だけが表示されます（例：`ランチ 1200`）。
- 結果は日付ごとに、新しい順に並びます。日付には年も表示されます。上部には件数と合計が表示されます。
- 結果の行も、タップしてなおしたり、左にスワイプしてけしたりできます。
- 「とじる」か戻るボタンで、もとの月の一覧に戻ります。

### 収入・貯金・固定費

- ホームの「今月使えるお金」をタップしてひらいた内訳の行からひらきます。左上の「‹」でホームに戻ります。
- 貯金は、内容（例：旅行、車）ごとに切り崩します。同じ目的の貯金は、毎月同じ名前で入れてください。
- 前の月の行は、一覧ごとにコピーできます。一覧が空のときは「◯月の固定費が◯件あります」と「◯月にコピーする」、行があるときは一覧の下の「◯月の固定費をコピーする」から（収入・貯金も同じです）。行があるときは、追加してよいかを先に確認します。押すたびにコピーされるので、重複した行はけしてください。

### 特別出費

- 旅行や冠婚葬祭など、生活費とは別に管理したい大きな出費です。
- 選んだ年の特別出費がすべて表示され、上部に年間の合計が表示されます。
- 「＋ つける」から「特別出費」を選び、日にち・内容・金額・どこから払ったか・メモを、この順に入れます。
- 日付の初期値は、選んだ月が今月なら今日、それ以外の月ならその月の1日です。
- 特別出費は、「今月使えるお金」「残りのお金」「先月の繰り越し」からは差し引かれません（仕様）。

### 切り崩し

- ホームの「貯金の内訳・切り崩し」でひらきます。先月までに貯めた貯金が、内容ごとに表示されます。
- 上に「◯月の残りのお金」が表示されます。ホームの残りのお金と同じ金額です。マイナス（赤字）のときは赤みのピンクになります。
- 行をタップすると「◯◯から切り崩す」シートが開きます。予算のシートと同じく、画面の上から中身の高さの分だけ開きます。金額を入れて「保存」すると、その月にその貯金から取り崩した額として記録されます。
- 切り崩したお金は、その月の「残りのお金」に足されます。
- シートには「切り崩したあとの残りのお金」が表示され、金額を入れるたびに変わります。マイナスのままのときは赤みのピンクです。
- その行の貯金より多い金額は入れられません。
- 切り崩しをやめるときは、行を左にスワイプして「けす」をタップします。「もとに戻す」で戻せます。
- 「残りのお金を翌月に繰り越す」がオフのときは、この画面に「先月までに残ったお金（貯金を除く）」も表示されます。

## 入力のきまり

- 金額は1円以上の整数を入れてください。カンマや全角数字も使えます。
- 日付は2020年1月1日から2100年1月1日までです。
- 入力に問題があるときは、シートの金額の下に、何を直せばよいかが表示されます（例：「金額を入力してください。1円以上の金額を登録できます」）。

## 設定

| 項目 | 内容 |
|---|---|
| テーマ | システム・ライト・ダークから選びます。選ぶとすぐに切り替わります |
| 「＋ つける」の位置 | 画面の下の右と左から選びます。選ぶとすぐに、どの画面でも切り替わります |
| 指紋認証 | オンにすると、起動時に指紋認証を求めます |
| 残りのお金を翌月に繰り越す | オンにすると、先月までに使い切らなかったお金を今月の「使えるお金」に加えます |
| バックアップを作成 | 今の記録をすべて、1つのファイルに保存します |
| バックアップから復元 | 保存したファイルの記録に置き換えます |
| 使い方 | すぐに使いはじめるための案内を、もう一度ひらきます |
| くわしい使い方 | 「使い方」で説明していない、予算・貯金の切り崩し・繰り越し・「＋ つける」の位置の案内をひらきます |

- 設定は端末に保存され、次回起動時にも引き継がれます。

### バックアップと復元

機種変更のときや、記録を残しておきたいときに使います。

1. 「設定 › バックアップを作成」をタップします。
2. 保存する場所を選び、「保存」をタップします。ファイル名は`kakeibo-backup-20261016-0930.db3`のように、作成した日時になります。
3. 戻すときは「設定 › バックアップから復元」をタップし、保存したファイルを選びます。
4. ファイルに入っている記録の件数と設定が表示されます。「置き換える」をタップすると、そのファイルの記録に戻ります。

- バックアップには、収入・貯金・固定費・生活費・特別出費・予算・種類の記録がすべて入ります。「指紋認証」と「残りのお金を翌月に繰り越す」の設定も入ります。テーマと「＋ つける」の位置の設定は入りません。
- 復元すると、この2つの設定もバックアップのときの状態に戻ります。ただし、指紋認証が使えない端末（指紋を登録していないなど）では、起動できなくならないように、指紋認証はオフのままにします。
- 復元すると、今の記録はすべてファイルの記録に置き換わります。置き換える前の記録は、念のためアプリの中に1つだけ残します（次に復元するときに上書きされます）。
- 家計簿のバックアップではないファイルを選んだときは、「このファイルは使えません」と表示され、記録は変わりません。
- 別の端末に移すときは、ファイルをクラウドやパソコンなどにコピーしてから、新しい端末で復元してください。
- 画面の下に、アプリのバージョンが表示されます。

## アプリ内の使い方

アプリの中の説明は、実際の画面を指し示しながら進みます。説明する部分だけを明るく残して周りを暗くし、吹き出しで説明します。「次へ」で進み、「戻る」で前の説明に戻ります。「スキップ」でいつでも閉じられます。必要なときは、自動で生活費・特別出費・設定のタブに移ります。

- 吹き出しは、1つの案内の中ではいつも同じ位置に表示されます。「＋ つける」を説明するページがある「使い方」では、そのボタンの上に表示されます。「くわしい使い方」では、下のタブのすぐ上に表示されます。
- 指し示す部分が吹き出しに重なるページだけは、吹き出しを画面の上に表示します。設定の「使い方」のように画面の下のほうにある部分や、長くて吹き出しの上に収まらない部分（画面の短い端末や、「先月の繰り越し」の行があるときなど）です。指し示す部分は、吹き出しより下にあれば動かしません。吹き出しに隠れてしまうときだけ、吹き出しの下まで移します。
- 下のタブは暗くしません。選ばれているタブを見ると、どの画面の説明かがわかります。説明の間は、タブは押せません。
- 指し示す部分は、ふだんの画面がスクロールできる範囲の中で、画面の上（上に少し余白を残した位置）に近づけます。画面の下のほうにある部分は、ふだんどおりの位置に表示されます。吹き出しを画面の上に移しても収まらないほど長い部分は、吹き出しの後ろまで続けて全体を囲みます（下のタブの手前まで）。
- 案内の間は、記録の有無にかかわらず、ホーム・生活費・特別出費のタブの金額をすべて見本の金額（収入¥250,000、生活費¥6,100など。娯楽は予算をオーバーしています）にして説明します。見本の金額で説明しているページでは、吹き出しの右上に「見本の金額」と表示されます。見本の金額は保存されず、案内を閉じると記録した金額の表示に戻ります。
- 使い方を閉じると、ホームの先頭に戻ります。

説明は2種類あります。「使い方」は、はじめに必要なことだけを説明します。「くわしい使い方」は、それ以外のことを説明します。2つの間で、同じ説明はしません。

### 使い方（すぐに使いはじめるための案内）

はじめて起動したときと、アップデートしたあとはじめて起動したときに表示されます。指紋認証がオンの場合は、認証のあとに表示されます。「設定 › 使い方」から、いつでももう一度ひらけます。

| ページ | 指し示す場所 | この文書の該当箇所 |
|---|---|---|
| 1. このアプリでできること | ホーム全体（明るくする部分はありません） | このページのはじめ |
| 2. 今月使えるお金を入れる | 収入・貯金・固定費のカード | 「ホーム」の「今月使えるお金」、「一覧」の「収入・貯金・固定費」 |
| 3. 生活費をつける | ホームの「＋ つける」 | 「＋ つける」、「生活費をつける」 |
| 4. 残りのお金と今月のペース | ホームの残りのお金のカードの、金額と2本のバー | 「ホーム」の「残りのお金と今月のペース」 |
| 5. 特別出費をつける | 特別出費タブの「＋ つける」 | 「＋ つける」、「一覧」の「特別出費」 |
| 6. もっと知りたいときは | 設定の「使い方」と「くわしい使い方」 | 「設定」 |

はじめに、アプリのしくみ（収入から貯金と固定費を引いた「今月使えるお金」の中で、生活費をやりくりすること）を説明します。次に、今月使えるお金（収入・貯金・固定費）と生活費の入れ方を説明し、入れた結果としてホームに表示される残りのお金と今月のペースを説明します。そのあとで、残りのお金とは別枠の特別出費のつけ方を説明します。なおし方とけし方は、一覧の上に表示される案内で確認できます（「一覧」の「なおす」「けす・もとに戻す」を参照）。

最後のページで、予算・貯金の切り崩し・繰り越しは「くわしい使い方」で説明していることを伝えます。

### くわしい使い方

「使い方」で説明していないことを、1つの案内で説明します。「設定 › くわしい使い方」からひらきます。自動では表示されません。

| ページ | 指し示す場所 | この文書の該当箇所 |
|---|---|---|
| 1. 予算を決める | 生活費のカード | 「ホーム」の「生活費（種類ごとの予算）」 |
| 2. 貯金の内訳・切り崩し | 貯金の内訳・切り崩しの入口 | 「一覧」の「切り崩し」 |
| 3. 切り崩したとき | 残りのお金のカードの、金額と2本のバー | 同上 |
| 4. 繰り越し | 設定の「残りのお金を翌月に繰り越す」 | 「設定」 |
| 5. 「＋ つける」の位置 | 設定の「「＋ つける」の位置」 | 「設定」 |
